# Component state styles

`src/styles/component-variants.css` preserves the component state variants,
accordion keyframes and scrollbar utility previously imported from
`shadcn@4.11.0/dist/tailwind.css`. They are kept locally to avoid installing the
component generator and its CLI/server dependencies with the application.

Source: [shadcn/ui](https://github.com/shadcn-ui/ui).
